# CCNA Packet Tracer Labs

This repository contains my hands-on networking labs based on **Jeremy's IT Lab CCNA 200-301 course**.

## Technologies & Tools
- Cisco Packet Tracer
- Cisco IOS CLI
- GitHub

## Labs
- Basic Network Configuration
- VLANs and Trunking
- Inter-VLAN Routing
- Static Routing
- OSPF
- DHCP and NAT
- Access Control Lists (ACLs)
- Network Troubleshooting

## Purpose
To develop practical networking skills, gain hands-on experience with Cisco networking concepts, and build a portfolio of network engineering projects while studying for the CCNA certification.
